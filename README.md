# Nota Pembukuan PWA

Aplikasi Progressive Web App untuk mencatat belanja & pembayaran supplier dengan sistem nota berjalan.

## Fitur Utama

- 📊 **Kelola Toko** - Manage multiple supplier/toko
- 📝 **Catat Belanja** - Pencatatan barang masuk harian dengan auto-total
- 💰 **Catat Pembayaran** - Pembayaran cicilan/lunas dengan tracking
- 📋 **Lihat Laporan** - Dashboard dan history transaksi
- 📱 **PWA** - Offline-first, installable, responsive mobile

## Sistem Nota

- Setiap toko punya **nota terpisah per periode**
- Setiap nota otomatis punya **target bayar 7 hari**
- Bisa **cicilan atau lunas** kapan aja
- Track **sisa hutang** sampai lunas
- Color coded: **HUTANG / CICILAN / LUNAS**
